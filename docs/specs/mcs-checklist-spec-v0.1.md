# MCS Checklist Spec v0.1

## Purpose

MCS introduces explicit meta-cognitive supervision upstream of authorization.

## Core checks

- Premises declared
- Regime declared
- Constraints declared
- Branch alternatives considered
- Contradictions surfaced
- Completion state declared
- Confidence aligned with support
- Missing evidence acknowledged

## Output shape

An MCS report may include:

- `status`
- `checks[]`
- `violations[]`
- `warnings[]`
- `summary`
- `recommended_gate_bias`

Phase 3 shadow mode is completed. Public repo work should preserve this as a documented pre-binding state.
